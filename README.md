# Navíos · animación ASCII

Una gota hecha cursor de texto cae sobre un mar de palabras, el mar se vuelve un sistema solar y la cámara se aleja hasta mostrar una galaxia. Todo se dibuja en un canvas con caracteres de texto.

## Cómo verla

- En línea: activa GitHub Pages (Settings → Pages → rama `main`, carpeta `/ (root)`).
- En local: sirve la carpeta con cualquier servidor estático (por ejemplo `python3 -m http.server`) y abre `http://localhost:8000`.

Toca la pantalla para empezar y vuelve a tocar para pausar. La barra inferior permite saltar a otro punto.

Esta versión no incluye audio y se reproduce en silencio. Con "cargar audio (opcional)" cada persona puede elegir su propio archivo de la canción para que la animación suene y se sincronice (la animación está calculada para una pista de 1:28).

## Archivos

- `index.html`: la animación.
- `datos.js`: datos de sincronización (bandas de frecuencia y tiempos de las notas). No contiene audio.
